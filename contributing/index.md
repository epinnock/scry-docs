# Contributing to Scry

Thank you for your interest in contributing to Scry!

## Ways to Contribute

- **Report bugs** - File issues for problems you encounter
- **Suggest features** - Propose new features or improvements
- **Improve documentation** - Fix typos, add examples, clarify explanations
- **Submit code** - Fix bugs or implement new features
- **Help others** - Answer questions in discussions

## Getting Started

1. **Read the documentation** - Understand how Scry works
2. **Set up your environment** - Follow the [Development Setup](/contributing/development)
3. **Find an issue** - Look for `good first issue` labels
4. **Make changes** - Follow our [Code Style](/contributing/code-style)
5. **Submit a PR** - Follow the [Pull Request](/contributing/pull-requests) process

## Repository Structure

Scry consists of multiple repositories:

| Repository | Description |
|------------|-------------|
| `scry-node` | CLI tool (`@scry/storybook-deployer`) |
| `scry-storybook-upload-service` | Upload Service (Cloudflare Worker) |
| `scry-cdn-service` | CDN Service (Cloudflare Worker) |
| `scry-developer-dashboard` | Dashboard (Next.js) |

## Code of Conduct

We follow the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

**Expected behavior:**
- Be respectful and inclusive
- Accept constructive criticism
- Focus on what's best for the community
- Show empathy towards others

**Unacceptable behavior:**
- Harassment or discrimination
- Trolling or insulting comments
- Publishing others' private information
- Other conduct inappropriate for a professional setting

## Getting Help

- **Questions:** Open a [Discussion](https://github.com/epinnock/scry/discussions)
- **Bugs:** File an [Issue](https://github.com/epinnock/scry/issues)
- **Security:** Email security@scry.com
